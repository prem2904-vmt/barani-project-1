Tabular Numbers (.pf-num Rule)

Monospace is never used for IDs, specimen accession numbers, dates, or prices. Instead, use Noto Sans with font-variant-numeric: tabular-nums via the .pf-num class so digits align in vertical columns without jitter.

Engineering & UX Non-Negotiables

Every screen in Prefrontal follows these core principles without exception.

1. Primary Gradient ONLY on the Single Main CTA

The signature violet→pink gradient pill (--gradient-primary) is reserved strictly for the ONE primary action on any view (e.g., "Confirm Order", "Collect Specimen"). Secondary actions must use slate outlines or quiet borders.

2. The Hero Band is Continuous & Never Becomes a Page Title

The top band (pf-hero-band) always shows the back chevron, tenant logo mark, and tenant name. Its enclosed pill is the CONTEXT BAR for the step (search or read-only subject chips with counts).

3. Two Jobs on One Screen = Main Card + Side Card Split

Layouts use .pf-body--split. Main work card sits on the left, companion side card (~400px) sits on the right with sticky footer buttons.

4. Zero Native HTML Controls

Never use native <select>, browser checkboxes, or native date pickers. Always use pf-select, pf-segmented, pf-date, and pf-toggle.

5. Bottom Navbar is Always Visible

All screens, sheets, and drawers fit above the bottom navbar (--pf-botbar-h) and never hide it.
